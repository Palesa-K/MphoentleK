# LinkedIn Learning certificate portfolio update

Two original 2025 LinkedIn Learning certificates have been added to a **Certifications** section on the main portfolio page.

- **Cisco Networking Foundations: IP Addressing**, course completed 12 April 2025, 1 hour 35 minutes
- **Learning IP Addressing**, course completed 11 April 2025, 40 minutes

Each card displays an image preview and links to the unchanged, user-uploaded PDF in `assets/certificates/`. The cards are described as **course completions**, rather than external industry exams. The included PDFs display the learner name and certificate ID, as issued by LinkedIn Learning. This is intended for a public professional portfolio. If you prefer not to make certificate IDs publicly available, do not publish these PDF files.

## Install
1. Extract the portfolio ZIP.
2. Copy all contents into your existing `Documents/GitHub/MphoentleK` repository folder, replacing matching files. Do not delete `.git`.
3. Open `index.html`. Click **Certifications** at the top, then test both preview images, **View certificate** and **Download PDF** links.
4. In GitHub Desktop, select **Commit to main**, followed by **Push origin**.

All prior website projects and the public CV are preserved.
