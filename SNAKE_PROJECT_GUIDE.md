# Mphoentle Keikabile — Computer Engineering Portfolio

This is the source for a static GitHub Pages portfolio.

## View locally

Open `index.html` in your browser and click the **Interactive Snake Game** card.

The Snake game is also available directly at `snake-game/index.html`, and the independent WebGL demonstration is at `snake-game/webgl-demo.html`.

## Files for the Snake Game

- `snake-game/index.html`: game interface and keyboard / on-screen controls
- `snake-game/style.css`: independent dark-green game theme
- `snake-game/script.js`: original assignment-based game logic with usability fixes
- `snake-game/assets/snake2.png`: title illustration from the submitted game
- `snake-game/webgl-demo.html`: stand-alone WebGL study
- `snake-game/webgl-demo.js`: WebGL buffers and GLSL shaders
- `assets/snake-game-preview.webp`: generated screenshot of the running game
- `projects/snake-webgl.html`: public-facing project explanation

The original report is deliberately **not** included online because it displays a student number. The supplied watermarked snake texture is excluded from the public website; the game uses a CSS-generated green snake instead. The Japan flag image is not referenced in the game and is also omitted.

## Publish

Place all files into the existing GitHub repository folder (preserving the hidden `.git` folder). In GitHub Desktop: commit and push. Then enable GitHub Pages from `main` and `/ (root)`.
