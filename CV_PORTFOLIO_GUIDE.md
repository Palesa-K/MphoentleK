# Adding your CV to MphoentleK portfolio

This website adds a **CV** navigation link, a **View my CV** hero button, and a dedicated **CV section**. The links open/download `assets/Mphoentle_Keikabile_Public_CV.pdf`.

The included PDF is a **public-sharing copy** of your uploaded two-page CV. The original styling and wording are preserved, but date of birth, gender and telephone number were redacted to reduce public exposure of personal information. The original private PDF is **not** included in the website archive.

## Install

1. Extract this archive.
2. Copy its contents into `Documents/GitHub/MphoentleK` (or your actual GitHub repository folder). Replace matching files but do **not** delete `.git`.
3. Open `index.html` in your browser. Click `CV`, `View my CV`, and `Download PDF` to test.
4. When it looks right, use GitHub Desktop to **Commit to main** and **Push origin**.

This PDF still reflects your uploaded CV's qualification status (final year / expected completion 2026). Update that if your status changes, before you publish or send it to recruiters.
