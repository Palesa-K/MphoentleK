# Personal profile photo added

Your profile cover is now displayed in the home page hero section. The original seven projects, CV, and LinkedIn Learning certificates are preserved.

## Update your GitHub Pages site
1. Extract this ZIP and copy the files into your existing `MphoentleK` GitHub repository folder.
2. Choose Replace for changed files. Do not delete the `.git` folder.
3. In VS Code or Chrome, open `index.html` to preview the new photo.
4. In GitHub Desktop, commit with a summary such as `Add profile cover photo` and click **Push origin**.
5. Wait for your GitHub Pages deployment and refresh the public URL.

The cover image is located at `assets/profile-hero.webp` and appears behind the white homepage introduction on wide screens. On narrow screens it appears above your introduction.

If you would prefer the unedited photo instead, replace that image with your original photo (converted to WebP) and retain the same filename.
